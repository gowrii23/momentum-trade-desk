Data Import — NSE Bhavcopy

NSE publishes the full daily market file free, no key required, at:
https://nsearchives.nseindia.com/content/cm/BhavCopy_NSE_CM_0_0_0_YYYYMMDD_F_0000.csv.zip
NSE blocks scripted/cross-origin requests from browser pages (bot protection), so this app can't pull it automatically — open the folder, download the day's zip, and drop it below. Each file covers the whole market for that day, so uploading a few days builds real technicals (SMA/ATR/RS) across every symbol, not just one stock. Fundamentals (EPS/ROE) and news still need to come from you — bhavcopy has neither.
