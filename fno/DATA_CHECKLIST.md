# NSE download checklist — NIFTY monthly options + NIFTY 50 index

Generated by `fno_backtester.py checklist` on 20-Oct-2026. Full table: `output/nse_download_checklist.csv`.

## How to download (phone)

1. Chrome → ⋮ menu → tick **Desktop site** (NSE's forms work far better that way).
2. Open https://www.nseindia.com/resources/historical-reports-capital-market-daily-monthly-archives
3. **Options files:** Derivatives → *Contract-wise Price Volume Data* → Instrument **Index Options**, Symbol **NIFTY**, Year, **Expiry** (pick from the dropdown), Option type **CE** or **PE**, Strike price **blank**, From / To as below → Download CSV.
4. **Index files:** Indices → *Historical Index Data* → **NIFTY 50**, From / To as below → Download CSV.
5. Optional benchmark: NIFTYBEES daily prices (Security-wise price volume data). If you skip it, NIFTY 50 price index is used (no dividends, no ETF fee).
6. Send the CSVs here (attach, or commit to `fno/data/raw/`). File names don't matter — the loader reads contents and reports what's really there.

**Trust the NSE dropdown's expiry date.** Dates here are computed (last Thursday to Aug-2025, last Tuesday from Sep-2025, moved earlier for holidays). 2026 holidays are verified from NSE's holiday page; before 2026 only fixed national holidays (26-Jan, 1-May, 15-Aug, 2-Oct, 25-Dec) are applied. If the dropdown shows a different date, use it as *To*, and keep *From* as shown.

**Why *From* starts 7 days before the previous expiry (not the day after):** the strategy needs ≥3 trading days to expiry, so in the last days of each month it must trade the *next* month's contract. Without this one-week overlap, every signal in those days would be skipped as NO_DATA. Overlapping rows are de-duplicated automatically. Every range is ≤ 45 days, well inside NSE's 90-day limit.

Counts: **5-year test = 120 option files + 31 index files = 151.** **3-year test (rows marked 3y) = 72 option files + 19 index files = 91.**

## Too many files? Smallest honest sample (55 files)

1. Download **all 31 index files first** (they are small and also give the benchmark).
2. I run `python fno_backtester.py suggest --index ...`. It labels every real month UP (>+2%), DOWN (<−2%) or SIDEWAYS from the NIFTY 50 closes and picks 4 of each, spread across the 5 years (and so across lot sizes 50 / 25 / 75 / 65).
3. You download only those **12 months × CE/PE = 24 option files.**

What a 12-month sample **cannot** prove: how losses compound over 3–5 continuous years, losing streaks, how often each kind of market actually happens (the sample forces a 4/4/4 mix), bust timing, or behaviour in a crash/regime not in the sample. It can show the per-trade economics (win rate, average win vs loss, costs per trade), which is what the Monte Carlo resamples — so the projection would be labelled even more tentative.
